# Alma Serena

Alma Serena es una aplicación web motivacional que ayuda al usuario a recibir una afirmación, un mensaje de ánimo y un versículo bíblico según cómo se siente.

## Descripción

El usuario escribe cómo se siente en un campo de texto. La aplicación analiza palabras clave relacionadas con emociones como tristeza, ansiedad, miedo, desmotivación, agradecimiento o alegría. Luego muestra una respuesta personalizada con:

- Una afirmación motivacional
- Un versículo bíblico
- Un mensaje de reflexión
- Una imagen relacionada con la emoción detectada

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript

## Cómo usar el proyecto

1. Abrir el archivo `index.html` en el navegador.
2. Escribir cómo te sientes en el campo de texto.
3. Presionar el botón para recibir un mensaje.
4. Leer la afirmación, el versículo y el mensaje generado.

## Funcionalidades

- Detección básica de emociones por palabras clave.
- Mensajes personalizados según la emoción.
- Versículos bíblicos aleatorios.
- Imágenes relacionadas con cada estado emocional.
- Botón para volver a intentar con otro mensaje.
